### 🚀 Featured Projects

- **⚡ [RagKit](https://github.com/Gurkan26/ragkit-android)** *(Maven Central: `io.github.gurkan26`)*
  Lightweight, modular on-device semantic search & RAG SDK for Android. Vectorizes text locally via MediaPipe and performs vector similarity search on Room SQLite with reactive `Flow` queries. (`Kotlin 2.0+`, `MediaPipe`, `Room`, `Coroutines/Flow`, `CI/CD`)

- **🤖 [ClaimPilot](https://github.com/Gurkan26/claimpilot)**
  Autonomous AI employee platform for tracking contracts, invoices, licenses, and recurring obligations with local LLM support. (`Go 1.26+`, `React`, `TypeScript`, `Electron`, `Ollama / Gemma 2`, `PostgreSQL`, `MongoDB`)

- **🧠 [Smart Emotion & Focus Journal](https://github.com/Gurkan26/smart-emotion-focus-journal-frontend)** • *([Backend](https://github.com/Gurkan26/smart-emotion-focus-journal-backend))*
  Cognitive workload and emotional state analysis platform running browser-embedded LLMs (`Web MLC-LLM` / `Gemma-2B`) backed by a multi-tenant, DDD/Clean Architecture Go SaaS backend. (`Next.js`, `Tailwind CSS`, `Go`, `Chi`, `PostgreSQL`, `Redis`, `Apache Kafka`)

- **💳 [Mova Wallet Dashboard](https://github.com/Gurkan26/MovaTask)**
  Modern FinTech wallet dashboard featuring family sub-wallets, transaction history, and reactive UI state management. (`Kotlin`, `Jetpack Compose`, `Material 3`, `Dagger Hilt`, `MVVM`)

- **🫁 Numa Breath Exercise**
  Modern guided breathing & wellness app with local persistence and subscription management. (`Jetpack Compose`, `Room`, `RevenueCat`, `Coroutines/Flow`)

- **📈 Binance Trade Assistant & 🌍 Earthquake Alert System**
  AI-assisted crypto trading companion (`Flutter`, `Python/Flask`, `OpenAI`, `Binance API`) and real-time USGS seismic alert system (`Flutter`, `Firebase`).
